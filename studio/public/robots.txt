# chopshop-studio — a private tool. Nothing here is for search engines.
#
# This is a crawler *request*, not access control. It politely asks well-behaved
# bots to stay away; it does not stop anyone who ignores it. The real protections
# are, in order of strength:
#
#   1. The login gate (CHOPSHOP_PASSWORD) — every controller now runs
#      `before_action :require_login`, including /about, /json and /jev.
#   2. X-Robots-Tag: noindex on every response (see
#      ApplicationController), which also covers files already indexed by a
#      crawler that saw them before this file existed.
#   3. This file, for anything that reads it.
#
# Serve this over HTTPS only. A robots.txt fetched over plain HTTP can be
# rewritten in transit, which would let a MITM downgrade the rules below.
